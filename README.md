## Project overview

This beginner-friendly project demonstrates an end-to-end data analytics and machine-learning workflow. It checks data quality, explores relationships using charts and summary statistics, compares regression models, and discusses how prediction results should be interpreted responsibly.

**Important dataset note:** the data analysed in this submission is a reproducible **synthetic dataset** of 600 simulated student records. It contains no real student information. Reported insights and metrics are only demonstrations of the workflow; they are not evidence about real learners or schools.

## Dataset

- **Dataset included with this repository:** [`student_performance_synthetic.csv`](student_performance_synthetic.csv)
- **Dataset size:** 600 rows and 11 columns.
- **Target column:** `final_score` (simulated score from 0 to 100).
- **Input columns:** study hours, attendance, previous score, assignment completion, sleep, extracurricular time, internet access, parent support, and tutoring sessions.
- **Public real-data reference for possible future work:** [UCI Student Performance dataset](https://archive.ics.uci.edu/dataset/320/student+performance). This notebook does **not** claim to analyse the UCI dataset; it analyses only the included simulated CSV.

## Main tasks

1. Inspect row/column counts, data types, missing values, duplicates, and numeric summaries.
2. Visualise score and study-hour distributions.
3. Explore score relationships with study hours, attendance, and numeric variables.
4. Preprocess numeric and categorical predictors without fitting preprocessing on the test set.
5. Compare **Linear Regression** and **Random Forest Regressor** using MAE, RMSE, and R².
6. Review Random Forest feature importances and outline responsible-use safeguards.

## Setup and run (Windows)

1. Install Python 3.10+ from [python.org](https://www.python.org/downloads/). During setup, enable **Add Python to PATH**.
2. Put the notebook, CSV, and `requirements.txt` in the same folder.
3. Open Command Prompt in that folder.
4. Create a virtual environment (recommended):

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

5. Install required libraries:

   ```bash
   python -m pip install -r requirements.txt
   ```

6. Start Jupyter:

   ```bash
   jupyter notebook
   ```

7. Open `HarshPareek_StudentPerformanceAnalytics.ipynb` and choose **Kernel → Restart & Run All**. Keep the CSV in the same folder so the notebook loads the included data. If the CSV is absent, the notebook can generate the sample automatically.

### Google Colab option

Upload both the `.ipynb` and `student_performance_synthetic.csv` into the same Colab session, then choose **Runtime → Run all**. If the CSV is not uploaded, the notebook generates the data itself.

## Model evaluation results

These values were measured on one fixed 80/20 train-test split of the synthetic dataset.

| Model | MAE (lower is better) | RMSE (lower is better) | R² (higher is better) |
|---|---:|---:|---:|
| Linear Regression | 5.659 | 6.853 | 0.575 |
| Random Forest | 6.425 | 7.957 | 0.427 |

The **Linear Regression** model had the lower RMSE in this run. Its test MAE was about 5.66 points. The dataset was simulated using a formula with largely additive relationships, so this result is illustrative and should not be generalised to real student performance.

## Responsible use and limitations

- The dataset is synthetic; results do not represent real students.
- Correlation and feature importance do not establish cause and effect.
- A single train-test split is not a complete model validation strategy.
- A real deployment would require authorised, representative, privacy-protected data, further validation, fairness checks, and human oversight.
- Predictions should never be used on their own to grade, discipline, or restrict opportunities for students.

## Reproducibility

Random seed: `42`. The same included CSV and notebook should produce the same sample and closely matching model scores when run with compatible library versions.
